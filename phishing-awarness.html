Exercise 2 : URL Inspection

https://secure-update-login.example/login
Things to verify:
  • Is the domain exactly the one you expect?
  • Is HTTPS present?
  • Are there unnecessary subdomains?
  • Did you arrive here from an unexpected email?
  • Never trust urgency alone.

Best Practices

  • ✔ Verify the website domain carefully.
  • ✔ Use multi-factor authentication.
  • ✔ Keep software updated.
  • ✔ Do not click unexpected links.
  • ✔ Report suspicious emails.
  • ✔ Be cautious with urgent requests.
  • ✔ Verify attachments before opening.
