🌐 DNS Cache Poisoning Attack

DNS spoofing (also known as DNS cache poisoning) occurs when an attacker corrupts a DNS resolver's cache with false records, redirecting users to malicious websites without their knowledge.

🛡️ DNSSEC Protection

🛡️ How to Protect Against DNS Spoofing:
  • 🔐 Use DNSSEC (DNS Security Extensions) to digitally sign DNS records
  • 🔐 Enable DNS over HTTPS (DoH) or DNS over TLS (DoT)
  • 🔐 Keep DNS server software updated against known vulnerabilities
  • 🔐 Use random source ports and transaction IDs (TXIDs)
  • 🔐 Implement response rate limiting on DNS resolvers
  • 🔐 Monitor for unusual DNS query patterns with anomaly detection
🚨 Signs You May Be a Victim:
  • 🌐 URL shows the correct domain but looks different in the browser
  • 🔒 SSL/TLS certificate warnings (mismatched domain)
  • 📧 Phishing pages load despite typing correct URLs
  • 💳 Unexpected payment gateways when visiting known sites
  • 🔍 Use 'nslookup' or 'dig' to verify IP resolution matches expected
