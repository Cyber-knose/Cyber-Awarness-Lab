🛡️ Protection

🛡️ How to Protect Against MFA Fatigue:
  • 🔐 Use hardware security keys (FIDO2/U2F) instead of push notifications
  • 🔐 Enable number matching in push notifications (Microsoft Authenticator)
  • 🔐 Set rate limits on MFA push notifications (max 3 per hour)
  • 🔐 Use contextual MFA — only trigger on expected geolocation/device
  • 🔐 Train users to NEVER approve unexpected MFA prompts
  • 🔐 Use passwordless authentication (passkeys, Windows Hello)
  • 🔐 If you receive unexpected push — change password immediately!
