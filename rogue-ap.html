📶 Rogue AP Attack Scenario

A rogue access point is an unauthorized Wi-Fi AP installed on a secure network without IT knowledge. Attackers use them to bypass security controls and capture sensitive data.

🛡️ Detection & Prevention

🔍 How to Detect Rogue APs:
  • 📶 Conduct regular wireless site surveys (e.g., using Ekahau, NetSpot)
  • 🔍 Use WIDS/WIPS (Wireless Intrusion Detection/Prevention Systems)
  • 📋 Maintain an inventory of authorized MAC addresses
  • 🔐 Implement 802.1X with mutual authentication (EAP-TLS)
  • 📡 Monitor for MAC address spoofing and SSID overlaps
🛡️ Prevention Measures:
  • 🔒 Use WPA3-Enterprise with certificate-based authentication
  • 🔌 Disable unused switch ports to prevent physical AP installation
  • 📡 Enable AP location tracking via RF fingerprinting
  • 🔐 Implement Network Access Control (NAC)
  • 📋 Regular security audits and penetration testing
