🎭 Deepfake Scam Awareness

Deepfakes use AI to create hyper-realistic fake videos and audio. Scammers impersonate executives, celebrities, or loved ones to steal money.

✅
REAL: CEO recorded last week
Natural eye movement, consistent lighting
🚩
FAKE: Deepfake of CEO
Unusual blinking, audio sync issues

Real-World Case (2019): Energy firm CEO received a phone call from what sounded like his parent company's CEO — the voice was AI-cloned. He transferred $243,000 to a fraudulent account. The voice was a deepfake.

🔍 How to spot deepfakes:
  • 👁️ Unnatural blinking patterns or lack of blinking
  • 🎤 Audio desync — mouth movements don't match speech
  • 💡 Inconsistent lighting and shadows on the face
  • 📐 Unusual head angles or facial warping at edges
  • 🔐 Establish a verbal code word for financial requests

🎤 AI Voice Clone Fraud

Attackers use AI voice cloning tools (like ElevenLabs, Respeecher) to impersonate someone's voice with just 3-10 seconds of audio.

⚠️ How AI Voice Cloning Works

  1. 🎤 Attacker extracts 10-30 seconds of audio from social media (TikTok, Instagram, YouTube)
  2. 🧠 AI model (e.g., ElevenLabs, TorToiSe) trains on the voice sample
  3. 📝 Attacker types any script and generates the voice in real-time
  4. 📞 Caller ID is spoofed to match the victim's expectation

💉 Prompt Injection Demo

Prompt injection is an attack where a user crafts input to override an AI's safety instructions, making it behave outside its intended guidelines.

🛡️ Defending Against Prompt Injection:
  • 🔒 Use input sanitization and instruction boundaries
  • 🛡️ Implement separate system prompts that are non-overridable
  • 🔍 Monitor for jailbreak attempts in user inputs
  • 📋 Use output filtering to prevent sensitive data leakage

🔓 LLM Data Leakage Awareness

Employees pasting sensitive data into public AI tools (ChatGPT, Claude, Gemini) can leak confidential information — it may be used for training or exposed to others.

🚨 Real Incident: Samsung ChatGPT Leak (2023)

Samsung employees pasted confidential source code, meeting notes, and performance data into ChatGPT. The data was used for training and could appear in responses to other users. Samsung banned ChatGPT shortly after.

📋 Example of Data Leakage Risks:

// ❌ Employee pastes this into ChatGPT: "Here is our company's AWS secret key: AKIAIOSFODNN7EXAMPLE Can you help me debug this Lambda function for our production customer database containing 2.4M records?" // ⚠️ This data could be used for future model training!

🛡️ Safe AI Usage Guidelines

  • ✅ Use enterprise AI tools with data privacy guarantees (no training usage)
  • ✅ Anonymize or redact sensitive data before pasting into AI tools
  • ✅ Never paste API keys, passwords, PII, or trade secrets
  • ✅ Check your company's AI usage policy before using public tools
  • ✅ Consider self-hosted LLMs for sensitive workloads
